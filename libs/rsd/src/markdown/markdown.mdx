# Markdown

Container for markdown-rendered content, built with React Strict DOM.

This component provides a styled container for markdown content. The actual
markdown parsing should be handled at the application level using an appropriate
library for your platform:

- **Web**: Use `markdown-it`, `remark`, or similar
- **Native**: Use `react-native-markdown-display` or similar
