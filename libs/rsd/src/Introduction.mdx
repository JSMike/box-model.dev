# Box Model RSD

React Strict DOM implementation of the Box Model design system. Everything stays boxy (zero radius) and token-driven, now with `html.*` and StyleX.

## Install & Import

<Source
  dark={true}
  format="dedent"
  language="bash"
  code={`
    npm install @box-model/rsd
  `}
/>

## Design Principles

- **React Strict DOM first** – Use `html.*` primitives and `css.create` for compile-time styles; no runtime StyleX.
- **Token-driven** – Style Dictionary emits `tokens.stylex.ts`, consumed via `css.defineVars()`; base styles import `tokens.css`.
- **Square edges always** – Borders and radii are zeroed across components to match the Box Model aesthetic.
- **Accessible defaults** – Stories mirror real markup; focus rings and typography come from tokens.
