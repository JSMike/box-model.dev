# Tooltip Box

Styles tooltip surfaces for supplemental guidance. Provide a trigger via `slot="trigger"` (or rely on the built-in dashed `?`) and place the tooltip message in the default slot. The tooltip only appears when the trigger is hovered or focused.

  dark={true}
  format='dedent'
  language="js"
  code={`

  `}
/>
